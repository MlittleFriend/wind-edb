# Wind EDB 原生底稿

目标是交付可由本机 Wind Excel 插件重新取数的底稿，而不只是公式字符串或静态数据。先查看当前环境是否有 Excel、已登录且有权限的 Wind、实际存在的 WindFunc.xla。离线环境仍可检查、准备连接，但不能声称已刷新。

## 默认工作方式：拿到底稿就开始取数

用户只需提供底稿、要什么数据、什么日期。Agent 自行定位公式、查找候选指标、准备配置和刷新核验；不要要求用户先整理代码、JSON 或全量指标字典。沿用当前任务授权，不把每个技术步骤变成确认请求。仅在统计口径存在实质歧义且上下文无法判断时询问。

1. **先建指标池，不要先碰 Wind 安装目录。** 指标代码不在 Wind 的 `etc`、`XLA`、`res` 里（那里是加密、压缩或只有财务指标，实测全部提取不出宏观 EDB 代码），而在用户自己的历史底稿里。先 `python scripts/pool_metrics.py --roots <指标库目录> --terms 关键词 --out pool.json` 扫一遍，通常几百个指标几秒钟到手。详见 [指标池](references/metric-pool.md)。
2. 执行 `python scripts/workbook_query.py search 底稿.xlsx --terms 居民 可支配收入`，先用少量关键词查找；无结果时换同义词、减少词项或去掉 --terms 列出所有已有指标。搜索仅做字面匹配，Agent 必须核对候选的完整名称、单位、频率和 changeRecord，不能自动取第一条。
2. 选定 search 返回的 sheet、anchor、code 后执行 `python scripts/workbook_query.py prepare 底稿.xlsx --sheet '实际表名' --anchor AD521 --codes M5481759 --start 2025-06-30 --end 2025-06-30 --output query.json`。示例地址与代码仅用于展示，不能硬套其他底稿。此步骤直接读取底稿配置，不需要用户手工提供模板。
3. 执行 `probe_excel.py --config query.json --output 新的小样.xlsx --addin 本机插件路径`，按下文验收日期、代码、单位、返回值与保存后的连接。需要回填正式底稿时，先在副本的空白取数页写入已核验连接，再按日期/代码引用；核对图表及源文件保护后按用户任务保存。脚本不会擅自覆盖原底稿。没有 pywin32 时改用 `scripts/edb_write.ps1`，流程等价。
4. 底稿和指标池里都没有目标指标时，再通过可用的 Wind 指标浏览器/经验证的搜索接口查找并导出原生连接，或按 [指标池](references/metric-pool.md) 的邻近探测法做候选验证（必须用独立已知值验数，名称不可信）。浏览器/接口访问能力不足时，明确只缺哪条指标的发现路径，保留已完成工作；不声称能自动搜索全库，也不编造代码。发现候选后先核验名称/单位/口径，不仅检查函数是否返回数值。
5. 最终交付用户要的数据和可刷新工作簿，并简短列出指标、统计期、单位、核验结果。技术配置留在附带证据，不用一份方案或字典代替完成取数。

## 最关键的区别

本技能验证过的插件格式使用 `='WindFunc.xla'!edb()`，指标与日期等配置在**同一单元格的传统批注（Note / COM Comment）**中。批注是 Base64 编码的压缩 EDB 数据，不是普通来源说明。只有公式没有批注通常不足以恢复连接。不要使用线程式评论替代传统批注，不要清理、覆盖或改写连接批注为解释文字。

`=[1]!edb()` 中的数字是该工作簿的外部链接索引，不是指标代码，不能从另一文件硬抄。带参数的 EDB 或其他插件版本应保留其实际语法，不能强制转换为这里的无参数格式。

**`Wind` 是表头，不是错误。** 无参数 `edb()` 在没有批注、或 `WindFunc.xla` 未作为加载项打开时，会返回占位文本 `Wind`；正常返回时它同样占返回区第一行。本机实测 `=EDB("代码","起始","截止")`、`=EDB("代码")`、中文指标名、以及 `='WindFunc.xla'!edb(...)` 带参数直调，在该插件版本一律 `#VALUE!` 或只回显表头。所以"带参数不通"不等于"代码错了"——先把批注和 XLA 加载补齐，再判断代码。同理，返回区的"指标名称"行回显的是你传入的 `name`，**不能用来校验代码真伪**，只能靠数值量级和口径判断。

## 执行路径

涉及“某日期/某月/某季度/某年”“指定指标”“最近 N 期”时，先读 [指定指标和日期取数](references/specific-data.md)。使用 `prepare_query.py` 从已核验配置选择指标和设置日期模式，再通过原生 Excel 返回的日期列验收。不要仅修改 obsTo 而保留 ptFullPeriod；不要把统计期筛选说成历史时点数据。

1. **只读盘点。** 对 xlsx/xlsm 运行 `python scripts/edb_tools.py inspect 文件.xlsx --out 检查.json`。它不启动 Excel、不改文件；列出 EDB/WSET 锚点、批注解码结果、公式缓存错误、计算模式、图表/媒体哈希与外链。xls/xlsb 用原生 Excel 读取。先记录源文件 SHA-256，修改前备份；打开中的未保存内容须通过所属会话另存副本，不能用磁盘副本冒充当前状态。
2. **选择已验证模板。** 优先复用同机器同插件版本中正常工作的 EDB 锚点及批注。用 `inspect --configs-dir 工作目录` 导出连接 JSON。核对每个 metric 的代码、名称、单位、频率、累计/当期/同比口径及日期设置；不凭名字或代码形式猜测指标。新指标从 Wind 指标浏览器或已核验配置取得完整元数据。
3. **先做小样。** 阅读 [连接格式和原生写入](references/native-workflow.md)。使用 `probe_excel.py` 在新建的临时工作簿验证一条/少量指标；它不会修改正式底稿。若无权限、插件错误或超时，保留诊断并停止重复刷新，不换成静态值冒充连接。
4. **写入目标副本。** 配置批注先写，公式后写；为返回区域预留足够空白，核对现有内容、合并单元格、表、图表，避免溢出覆盖。日期/标题/指标数量变化会改变返回布局，先重新确认引用范围。对现有复杂底稿优先原生 Excel 编辑；不要用 openpyxl 或通用表格工具整本重存带插件、图片、图表和外链的工作簿。它们不能执行 Wind UDF。
5. **等待与保存。** 在自己创建的 Excel 实例中启用自动计算、CalculateBeforeSave，计算目标表并有限等待。`CalculationState == 0` 只是必要条件之一；检查返回数据的日期、行列数量、错误、末期值及独立来源/冻结值。新请求窗口含未发布期次时，不把缺值变成零。最后保存、重读磁盘文件，核对 `<calcPr>`、批注、公式及缓存。修改批注配置后不能仅沿用旧缓存。
6. **保护底稿。** 对比修改前后公式、值、图表来源、图表数量、图片哈希和来源备注；区分允许的数据修订与意外变化。图表数量相同不证明引用正确。刷新延长的数据范围必须核对图表是否跟随。不要仅为修复过期值划线而清除字体删除线。

## 验收与报告

分别报告：连接已写入、Excel 已返回数据、保存后已核验、业务口径/最新期次已核验。只有四项都有证据才称“刷新验收通过”。脚本返回数值和计算完成不等于确认最新期次；`inspect` 也不会自动签发成功结论。没有在线刷新条件时说明“已准备连接，未验证刷新”。

ETF 分类申赎等若已有正确的 `wset("etffundinflows",...)`，而无同口径 EDB，不强制替换。WindPy `w.edb()` 可作为获授权的独立取数核对途径，但不能代替用户要求的工作簿原生连接。

## 工具

- `scripts/edb_tools.py`：仅 Python 标准库，离线检查、导出配置、编码与解码、CRC 校验；遇到未知格式明确报错。
- `scripts/probe_excel.py`：Windows + Excel + Wind + pywin32；只创建新探针文件，带超时和证据 JSON。使用方法见 `--help`。进程退出只关闭自己 DispatchEx 创建的 Excel，不能关闭用户的 Excel 或 taskkill 所有 EXCEL.EXE。
- `scripts/prepare_query.py`：从核验过的模板中选择代码，生成单期、区间、最近 N 期的批注配置；不存在或有歧义的代码直接报错，不推测指标。
- `scripts/workbook_query.py`：直接搜索底稿已有指标，并从指定锚点生成日期查询配置，省去手工拆批注和挑模板文件。
- `scripts/pool_metrics.py`：跨目录批量解码多本底稿，池化成可检索的指标库（code/name/unit/freq/来源锚点），解决"底稿里没有目标指标"时先找代码的问题。
- `scripts/edb_write.ps1`：`probe_excel.py` 的 PowerShell 等价实现，pywin32 缺失时用它写批注、写公式、计算并读回实际返回区。
- [指标池与已验证代码](references/metric-pool.md)：建池命令、本机已核验的财政/税收/社零/GDP 代码表、邻近代码探测与数值验证、官方数交叉校验、写回后的连接复查。
- [格式、故障与操作示例](references/native-workflow.md)：实际写入及版本边界。

本技能不携带 Wind 登录凭据、商业数据或用户底稿。跨电脑仍需目标机器自身的 Wind 授权、插件与登录状态。
