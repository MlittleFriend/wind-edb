Wind EDB 底稿连接技能 v1.3

本机技能名：wind-edb
调用示例：
请使用 $wind-edb 检查这个 Excel 底稿的 Wind EDB 连接，保留图表和原有口径，实际刷新并核验保存结果。

安装：
把 wind-edb-skill.zip 解压，将 wind-edb 文件夹放到该 Agent 的技能目录。
部分 Agent（如 Codex）的常用位置为用户目录下 .codex/skills/wind-edb；自定义 CODEX_HOME 的机器使用其 skills 子目录。
如果当前会话尚未发现这个技能，可新开聊天；也可直接要求 Agent 读取 wind-edb/SKILL.md。
其他支持 SKILL.md 的 Agent 可按其自己的技能安装方式使用。

包含：技能指令、连接格式与故障说明、离线检查/批注编解码工具、原生 Excel 小样刷新工具、跨底稿指标池工具。
这是技能包，不是 Wind 插件本体，也不包含 Wind 授权、商业数据或任何用户底稿。
本包不含本地文件路径、账号、机器名或具体研究资料；示例路径均以 <指标库目录>、<Wind安装目录> 占位。
离线工具只依赖 Python 标准库；实际刷新需要 Windows、Excel、已登录且有权限的 Wind，以及 pywin32
（缺失时可改用附带的 PowerShell 写入脚本）。

适用环境与边界：
- 连接格式为实测兼容格式，不是 Wind 官方公开稳定协议；插件升级或换机器后应先做探针。
- 验证覆盖连接读取、批量编码/解码往返、原生刷新返回与保存后重读；不构成跨版本保证。
- 业务交付仍需核对统计日期、单位、频率、指标口径、图表引用及最新已发布期次。

v1.1 新增：指定指标与日期取数。
- references/specific-data.md：指标筛选、单期/区间/最近 N 期、统计期与发布日期、精确匹配到报告单元格。
- scripts/prepare_query.py：从已核验模板生成请求配置，拒绝未知/歧义代码、无效日期与冲突日期参数。
- 实测单期、全年区间、最近 2 期三种模式，返回日期与值均与全历史序列对应部分一致。
- 注意：筛选后的标题“时间区间”仍可能显示全历史覆盖范围，验收须看实际数据日期列。

v1.2 新增：从底稿直接上手。
- workbook_query.py search：按关键词定位底稿中已有指标、代码及公式锚点。
- workbook_query.py prepare：从选定锚点直接生成日期请求，无需用户整理代码字典或模板 JSON。
- 用户只需给出底稿、指标需求和日期，Agent 负责执行；底稿中不存在的新指标仍需可用的 Wind 检索途径，未实现全库自动搜索。

v1.3 新增：指标池与排障补强。
- scripts/pool_metrics.py：跨目录批量解码多本底稿，池化成可检索指标库（code/name/unit/freq/来源锚点）。
  按文件体积降序解码，几秒可处理数百个指标。这是“底稿里没有目标指标”时寻找代码的最高杠杆一步。
- scripts/edb_write.ps1：probe_excel.py 的 PowerShell 等价实现，pywin32 缺失时用它写入并读回实际返回区。
- references/metric-pool.md：常用宏观指标 ID 参考、邻近代码探测+数值验证法、公开统计口径交叉校验、
  写回后的连接复查清单。
- SKILL.md 修正两处易误判：返回 `Wind` 是**表头**不是错误；`=EDB(参数…)` 在该插件版本一律不通，
  不能据此判断代码有误。返回区“指标名称”行回显的是传入的 name，**不能用于校验代码真伪**。
- 负结果记录（可省去重复摸索）：Wind 安装目录的 etc/edb/EDBNew*.chs、etc/wdf/Indicator.xml、
  etc/Matrix/wind_IndicatorTree.dat、res/wings/.../formulaBasicIndicator.json、DataBrowse/XLA/WindFunc.xla
  均无法提取宏观 EDB 代码——分别是分词索引、加密、压缩、只含财务指标、纯加载项。
- 写入保护：用 Excel COM 修改无关单元格并保存后，原有 [1]!edb() 锚点、批注、外链均保留；
  openpyxl 等通用表格工具整本重存会丢失，故不要用它们处理带插件的底稿。

调用示例：
使用 $wind-edb 调取 2025 年上半年中国居民人均可支配收入累计值，保留 EDB 连接，并核对实际返回日期为 2025-06-30。
使用 $wind-edb 从我的历史底稿里找出某个指标的代码，取指定年份的值并与公开统计数据核对。
